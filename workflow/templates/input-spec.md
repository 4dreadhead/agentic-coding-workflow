# Template: input spec

Written by the operator. No formal requirements – a task may arrive as a single
line. The template is for when the operator wants to give structure up front and
save a round of questions.

```markdown
## What is needed
<one paragraph: what should appear, or what is broken>

## Why
<the reason: an incident, a request, a constraint. Helps the agent choose at forks>

## Known constraints
<what must not break, what must not be touched, deadlines, dependencies>

## Decisions already made
<if some choices are settled, list them so the agent does not re-ask>
```

A minimally sufficient input spec is the "What is needed" section alone.
Everything else the agent is expected to work out in step 1.
